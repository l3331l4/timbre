# Crawl Bandcamp and SoundCloud for the Catalogue

The underground music Timbre is for lives mostly on Bandcamp and SoundCloud, so Digging Agents fill the Catalogue by crawling them, not by waiting for label submissions or links Diggers add by hand. We have knowingly put off the Terms of Service and audio-rights risk this carries to get a useful Catalogue quickly. Revisit this before public launch.
